# moonrockz/extism

An [Extism](https://extism.org) host for MoonBit programs. A MoonBit program on native, Node.js or a
browser loads an Extism plugin, calls its exports and gets the results, with limits on memory and time.

The repository is new. The packages are empty, and no version is published yet. Read the
[overview](../../docs/overview.md) for the plan and the status.
